## Contract error codes

Frozen `#[contracterror]` codes from `crates/vaeltrix-types/src/errors.rs`. Returned on contract failure with explicit numeric tags.

| Code | Name | Description |
| --- | --- | --- |
| 1 | `NotAuthorized` | Caller lacks authorization or required signature from admin, observer, or bond authority. |
| 2 | `ProviderNotActive` | Provider status is suspended or exited; operations on this provider are disallowed. |
| 3 | `TemplateNotActive` | SLA template is proposed or deprecated, not currently in active state. |
| 4 | `InsufficientStake` | Commitment does not have enough unreserved stake to cover penalty or minimum stake. |
| 5 | `OutOfScope` | Payment amount, asset, direction, or corridor is outside the template scope. |
| 6 | `ClaimWindowClosed` | Claim filed after the template claim window has elapsed. |
| 7 | `DuplicateClaim` | A claim for this payment ID has already been recorded; duplicate filing rejected. |
| 8 | `InvalidEvidence` | Pause duration exceeds maximum hold duration, or evidence hash is invalid. |
| 9 | `NotInBreach` | Payment completed within target plus grace duration; no SLA breach occurred. |
| 10 | `ChallengeWindowOpen` | Attempted action before the challenge window has closed. |
| 11 | `OpenClaimsExist` | Commitment exit or excess withdrawal blocked while open claims remain unresolved. |
| 12 | `CooldownActive` | Exit cooldown period has not yet expired. |
| 13 | `UnknownObserver` | Observer address is not in the active observer registry. |
| 14 | `AlreadyAttested` | Observer has already cast an attestation vote on this claim. |
| 15 | `AlreadyInitialized` | Contract has already been initialized via constructor. |
| 16 | `NotInitialized` | Contract has not been initialized with required parameters. |
| 17 | `InvalidParams` | Parameters fail validation bounds (quorum, windows, fee bps, asset caps, etc.). |
| 18 | `UnknownProvider` | Provider ID does not exist in the registry. |
| 19 | `UnknownTemplate` | Template ID does not exist in the registry. |
| 20 | `UnknownCommitment` | Commitment ID does not exist in the bond contract. |
| 21 | `UnknownClaim` | Claim ID does not exist. |
| 22 | `ProviderNotVerified` | Provider home domain has not been verified by the designated verifier. |
| 23 | `ProviderExists` | Provider already registered for this domain and admin combination. |
| 24 | `TemplateExists` | Template version already exists. |
| 25 | `TimelockActive` | Governance action timelock has not expired; action is still pending. |
| 26 | `AssetNotAllowed` | Stake asset is not in the registry allowed stake assets list. |
| 27 | `AssetMismatch` | Stake asset does not match the template scope asset. |
| 28 | `AmountOutOfRange` | Amount is below minimum stake floor or exceeds allowable thresholds. |
| 29 | `NotCovered` | Payment initiation timestamp (t0) falls outside active commitment coverage period. |
| 30 | `CommitmentNotActive` | Commitment is not active (paused, exiting, or exited). |
| 31 | `ClaimNotOpen` | Claim status is not Filed or Challenged. |
| 32 | `AttestationWindowClosed` | Observer attestation window has expired. |
| 33 | `QuorumNotReached` | Quorum not reached among observer attestations. |
| 34 | `BelowMinStake` | Stake reduction or commitment amount falls below required minimum stake floor. |
| 35 | `StakeCapExceeded` | Total stake exceeds maximum allowed stake per commitment. |
| 36 | `PaymentIdMismatch` | Derived payment ID does not match the provided payment ID. |
| 37 | `UnknownSigner` | Signer is not in the provider registered signer set. |
| 38 | `TooManySigners` | Signer list length exceeds maximum permitted count. |
| 39 | `UnsupportedPenaltyModel` | Specified penalty calculation model is not supported. |
| 40 | `ArithmeticOverflow` | Math overflow or underflow detected in checked arithmetic operation. |
| 41 | `BondAlreadySet` | Bond contract address has already been set on the scoreboard. |
| 42 | `BatchExists` | Daily metrics batch for this commitment and period has already been anchored. |
| 43 | `InvalidPeriod` | Period start/end is not a multiple of 86400, length is not 86400s, or is in the future. |
| 44 | `NothingPending` | No pending governance action or admin transition found with the specified ID. |
